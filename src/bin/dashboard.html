How each commit is proven

Using only data read back from the store, the harness hashes every file into a Git blob id, rebuilds the Git tree from the manifest, and rebuilds the Git commit from the pail commit's author, committer, dates, message and parents. The rebuilt commit id must equal the GitHub commit id. SHA-1 covers every byte, path, mode and header, so a match means the commit is modelled byte for byte.
